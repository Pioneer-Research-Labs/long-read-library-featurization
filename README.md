# 📚 Library Featurization Pipeline

This Python script processes the results of `long-read-qc` run on long read sequencing library data into a structured and quality-controlled dataframe, suitable for downstream analysis. It loads raw data, computes read statistics, performs QC, and exports a final `Parquet` file.

## 🚀 Features

* Loads barcode and mapped insert data from input files.
* Calculates raw read lengths from fastplong fastq outputs.
* Performs merging and quality control of the datasets.
* Aggregates features across the dataset.
* Outputs a compact `Parquet` file for efficient storage and access.

## 📁 Input Requirements

```
--library_path: path to library files
--tesseract_library: Boolean, use if library consists of multiple pooled genomes, then library_path should point to the parent folder containing the subfolder long-read-qc outputs
```

Your `--library_path` should point to the subfolder of results generated by `long-read-qc`:

* Barcode files (format expected by `load_data`)
* Mapped insert files
* Raw read data (fastq or equivalent)

---

## 🏃 Usage

```bash
python pipeline.py --library_path /path/to/your/library
```

This will generate a file named `library_dataframe.parquet` inside the specified `--library_path`.

If you want to error correct the library dataframe to a ground truth barcode reference, you can run the `error_correct_library.py` script after running the main pipeline.

---

## 📤 Output

* **`library_dataframe.parquet`**: A processed and featurized dataframe ready for downstream analysis.

---

## 🛠 Modules Breakdown

* `load_data(path)`: Loads barcodes and mapped inserts.
* `calculate_raw_read_lengths(path)`: Computes read lengths from raw read files.
* `merge_and_qc_data(barcodes, inserts, lengths)`: Merges datasets and applies quality control filters.
* `aggregate_data(df)`: Aggregates features across barcodes.
